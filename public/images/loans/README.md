# Loan product hero images

Photography used on the **landing page** loan section and as defaults in the customer **Loans** catalog and admin **Loan products** table.

| File | Loan type |
|------|-----------|
| `personal.avif` | PERSONAL |
| `mortgage.avif` | MORTGAGE |
| `auto.avif` | AUTO |
| `business.avif` | BUSINESS |
| `education.avif` | EDUCATION |

Served at `/images/loans/<file>`. Admins can upload a custom image per product in **Loans → Loan products**; that overrides these defaults.
